# Provenance and changes

**Origin:** Concepts practised in University of Melbourne Introduction to Programming coursework (2023).

**Original files reviewed privately:** Assignment 1 (movie reviews, ratings and sentiment lexicon), Assignment 2 (CSV/GPS/Haversine), MST and exam archives. The MST and exam contents are deliberately not included.

**New portfolio implementation:**
- Independent functions, type hints, module entry points and clear exceptions.
- Fictional review and GPS records instead of supplied coursework data.
- A new small example lexicon instead of redistributing the AFINN resource bundled with coursework.
- Unit tests for both workflows, including validation and file handling.
- Documented limits and explicit AI-assisted refactoring/adaptation.

The repository is meant to demonstrate concepts practised during the course and skills subsequently refined; it should not be interpreted as a verbatim archive of work submitted in 2023.
